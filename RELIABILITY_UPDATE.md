# Gemini, notification navigation and portable backups

Unreleased source work requested on 2026-10-09 after the 1.3.0 release. No production deployment, installer, version bump or GitHub publication was performed for this iteration.

## Changes

- Settings → ACK AI retains the Hızlı/Güçlü selector and adds a collapsed model-name editor. Both proposed model IDs must produce usable text before the UI saves them. Failed tests preserve the current settings. Model IDs are validated in Rust and cannot change the Google endpoint. The native API key never reaches the frontend. Model settings are stored separately in the app configuration folder and included as optional backup data, with transactional restore/rollback. Old backups preserve current model names.
- Gemini 3 Flash uses explicit medium thinking for chat and low thinking for a short connection test. Chat waits at most 60 seconds for Powerful and 45 for Fast. HTTP 500/502/503 gets one retry within the same total time budget; quota, permission, invalid request and transport failures do not cause automatic retries or model switching. A successful HTTP status with no usable text no longer passes the connection test.
- Windows task/payment toasts use the existing app identity and an activation callback. Clicking while ACKDeck is running shows/unminimizes the main window and navigates to the original task/payment ID using the existing highlighted-record route. No arbitrary URL, shell or path is activated. Scheduling and delivery claim behavior remain unchanged. Fully exited ACKDeck does not become a background notification service.
- Settings → Veriler has two backup types: records-only JSON and files-included ZIP. Portable backups include referenced cached note/archive attachments and directly linked archive files, not project folders, executables, application targets or arbitrary directory trees. Missing, oversized or credential-containing files fail the export instead of silently producing an incomplete backup. Existing JSON backups remain readable.
- Portable restore previews records before confirmation, checks manifest/reference correspondence, duplicate entries, bounded uncompressed sizes, attachment content/type/size and safe filenames. It only writes new regular files into a unique app-owned folder; archived paths are rewritten and media receive new IDs, preserving original files. Failed local-data rollback retains imported files so recovery cannot lose a referenced attachment. A process interruption can leave an unused app-owned folder; original files are not deleted or overwritten.
- App page selection is a typed map. ACK AI/history, Settings, QR, IP, speed test and Archive load separate chunks. The first JS entry fell from approximately 592 KB to 470.5 KB (about 21%); launch time has not been benchmarked. Existing desktop/mobile layouts remain in place.

## Validation and limits

Desktop production build, 187 frontend tests and release source audit passed. Native checks and 30 Rust tests passed; one explicitly invoked live API test passed separately, with a usable Powerful reply and actual tool declarations in approximately 3.2 seconds. An earlier live attempt returned a provider error; no promise of uninterrupted provider availability is made. Controlled native HTTP tests cover server retry and no retry for quota/permission errors. ZIP tests cover real file/media relocation, duplicate/traversal/unknown references, missing files, credentials and preservation of a previous complete backup on failure.

29 checks on production frontend builds covered the existing desktop/mobile matrix plus new Settings layouts. A native API mock exercised model save/failure, ZIP preview/cancel/confirm, model backup fields and notification-to-task frontend routing. Native ZIP bytes were tested separately using isolated temporary directories. Existing physical Windows toast activation, installed upgrade and iPhone behavior are not inferred from those browser checks.

The app's localStorage stores have not been migrated to SQLite. This remains a separate storage migration with quota risk; introducing an asynchronous write-behind cache would incorrectly report successful saves before durable writes, so this change does not substitute one. Authenticode certificates and SmartScreen reputation were not changed. Optional study-block notifications were not added.

Official Gemini model/thinking reference: https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash . Model names can now be changed without changing source code when provider availability changes.
