# ACKDeck 1.4.0 — content, recovery and reminders

The user explicitly requested these features and direct commit, push, setup and GitHub publication on 2026-10-09. This request also authorizes releasing the existing unreleased reliability work documented in RELIABILITY_UPDATE.md; existing changes were preserved.

- ACK AI renders GFM Markdown, lists, tables, quotations and syntax-highlighted code with a copy action. HTML is skipped, unsafe URL protocols are rejected and remote images are represented by their alt text without requests. Markdown is shared with Notes in a lazy chunk.
- Notes offers Edit, Split and Preview views, a readable line width and a monospace editor. Existing plain text and autosave remain compatible.
- Lazy pages retain the app shell and show a static skeleton with an accessible loading status.
- Tasks combines project/unassigned filtering with the existing date/completion tabs.
- AI responses can be saved as notes, with duplicate-click protection and honest quota errors. Task extraction creates editable local drafts from list items, with explicit selection and save; it does not call Gemini or silently apply actions.
- Settings → Veriler → Son silinenler keeps task/note/archive/workspace/shortcut/subscription recovery records for 30 days. The recovery copy is persisted before deletion; damaged or full storage blocks deletion. Restart recovery and duplicate-ID guards preserve active records. Real linked files are never deleted. Expired rows cannot be restored and are physically pruned on subsequent captures. The trash is local and excluded from backup and phone sync, explicitly explained in the UI. The existing ten-second Undo remains available; Undo-restored entries are excluded from trash results.
- Weekly Plan adds opt-in Windows study reminders per program (at start, 15/30/60 minutes before). Defaults are off. Preferences are in ack-deck.study-reminders.v1, optionally included in JSON/ZIP record backups; old backups preserve them. Program/sync schemas are unchanged. The existing native sleeping queue and durable delivery ledger prevent repeated notifications; recurrence uses the program timezone, respects active/end settings and skips missed notification times. These reminders require ACKDeck running, including tray mode; they do not generate phone pushes or extra task records. Notification activation opens Weekly Plan.
- Tray adds Hızlı Not Al using the existing typed new-note route.
